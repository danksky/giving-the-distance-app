# Sponsor Profiles

Each sponsor profile is stored in its own folder with:

- `profile.json` - Contains all sponsor data
- Image files referenced in the JSON (stored in `public/sponsors/[sponsor-slug]/`)

## Image Files Required

For each sponsor, place the following images in `public/sponsors/[sponsor-slug]/`:

- `logo.png` - Business logo (recommended: 256x256px or larger, square)
- `cover.jpg` - Cover/banner image (recommended: 1200x400px or similar)
- `staff.jpg` - Staff photo (recommended: 800x600px or similar)
- `product1.jpg`, `product2.jpg`, etc. - Product photos (recommended: 600x600px or similar)
- `charity-[name].png` - Charity logos (recommended: 128x128px or larger, square)

See `balkan-grind-brooklyn-nyc/profile.json` for an example.
